#ГАЙД ПО 3 ЛАБЕ

1) Выстроить топологию вида PC-A --> S1 --> R1 --> PC-B

2) IP:
R1[0] - 192.168.0.1 /24
R1[1] - 192.168.1.1 /24

S1 - 192.168.1.2 /24 

PC-A - 192.168.1.3 /24 
PC-B - 192.168.0.3 /24

3) В свитче вбить:
show sdm prefer  
configure terminal  
sdm prefer dual-ipv4-and-ipv6 default  
end  
reload  

4) Выставлям IP на PC-A, PC-B. Пингуем их. (Не получилось МБ)

5) Заходим в терминал роутера и пишем
enable  
configure terminal  
hostname R1  
no ip domain-lookup  
  
enable secret class  
enable  
(password): class  
  
line console 0  
password cisco  
login  
exit  
  
line vty 0 4  
password cisco  
login  
exit  

service password-encryption
banner motd #Unauthorized access prohibited!#

6) Настраиваем интерфейс, подключенный в PC-B  
В R1 также пишем  
interface gigabitEthernet 0/0/0  
description Connection to PC-B  
ip address 192.168.0.1 255.255.255.0  
ipv6 address 2001:db8:acad:1::1/64  
ipv6 address fe80::1 link-local  
no shutdown  
exit  
(Что мы сделали?? - указали v4 адрес маршрутизатора, указали глобальный и локальный v6 адреса)

7) Теперь настраиваем подключение для S1
interface gigabitEthernet 0/0/1 
description Connection to PC-B  
ip address 192.168.1.1 255.255.255.0  
ipv6 address 2001:db8:acad:1::1/64  
ipv6 address fe80::1 link-local  
no shutdown  
exit

8) В R1 пишем: 
ipv6 unicast-routing  
copy running-config startup-config  

9) Ставим время в роутере (R1): clock set ЧАСЫ:МИНУТЫ:СЕКУНДЫ ДЕНЬ МЕСЯЦ ГОД

10) Пингуем с PC-A, PC-B  

11) Настраиваем Свитч (S1)  
enable  
configure terminal  
hostname S1  
no ip domain-lookup  
interface vlan 1  
ip address 192.168.1.2 255.255.255.0
no shutdown  
exit  
ip default-gateway 192.168.1.1  
end  
copy running-config startup-config  

12) Пингуем PC-B с PC-A и S1

13) Смотрим с роутера инфу  
R1# show ip route  
R1# show ipv6 route  
R1# show ip interface gigabitEthernet 0/0/1  
R1# show ipv6 interface gigabitEthernet 0/0/1  
R1# show ip interface brief  
R1# show ipv6 interface brief  

14) Смотрим со свитча инфу: S1# show ip interface brief  

## Вопросы  
1) чтобы включить интерфейс G0/0/1 надо вбить  
interface g0/0/1  
no shutdown  
  
2) Если мы вобьем на интерфейсе G0/0/1 адрес 192.168.1.2, то возникнет конфликт айпишников с интерфейсом VLAN 1 свитча, что нарушит связь
